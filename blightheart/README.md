# Сердце Заражения (Blightheart) — NeoForge 1.21.1

Поставь Сердце Заражения: оно начнёт превращать землю вокруг в заражённую массу,
порождать существ и убивать всё живое рядом. Разбей Сердце — и всё созданное им погибнет.

Сборка: GitHub Actions (вкладка Actions → Artifacts → mod) или gradlew build (JDK 21).
Готовый мод: build/libs/blightheart-1.0.0.jar → папка mods профиля NeoForge 1.21.1.

Защита построек: /gamerule mobGriefing false — Сердце перестанет распространяться.
